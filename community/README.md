# 社区修谱投稿区

这里用于展示群友修出的候选 MIDI。它与 [CATALOG.md](../CATALOG.md) 中的默认可演奏版分开：候选文件可以下载和讨论，但只有经过审核并由维护者指定的版本才会成为普通玩家默认下载项。飞书、抖音群等渠道的投稿可先复制 [群聊投稿模板](群聊投稿模板.md)。

## 目录规范

```text
community/
├─ README.md
├─ 群聊投稿模板.md
├─ _template/
│  ├─ README.md
│  └─ submission.yml
└─ <曲目英文标识>/
   └─ candidate-<GitHub-ID>-v<版本号>/
      ├─ <曲目>_candidate.mid
      └─ submission.yml
```

## 展示表格

维护者在本文件追加投稿条目即可。推荐格式：

| 曲目 | 投稿者 | 状态 | 版本 | 导入设置 | 已试听平台 | 下载 | 改动说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 示例曲目 | `@GitHub-ID` | 待审核 | v1 | 音高 `0`；速度 `1.0`；其他：无 | 请填写 | 投稿合并后填写实际 MIDI 下载链接 | 这是填写格式示例，不含真实 MIDI。 |

状态只使用：`待审核`、`已验证候选`、`已替换为默认可演奏版`、`已归档`。

真实投稿的下载链接格式如下；把占位文字替换为实际文件名即可：

```md
[下载 MIDI](<曲目英文标识/candidate-GitHub-ID-v1/曲目_candidate.mid?raw=1>)
```

“导入设置”必须与同目录的 `submission.yml` 一致。音高以半音记录：`-12` 即降一个八度；无法确认时写“待确认”，不能默认填写为 `0`。非默认关键参数可写入 MIDI 文件名作醒目提示，但不得替代这些字段。

本 README 的表格是社区候选的唯一展示目录。每个合并的投稿 PR 都应同时补充或更新相应的一行。

GitHub 不会播放 MIDI；“下载”链接是正常展示方式。若投稿者另有权公开试听音频或钢琴卷帘图，可额外添加预览链接。
