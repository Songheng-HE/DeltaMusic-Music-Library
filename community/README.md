# 社区修谱投稿区

这里用于展示群友修出的候选 MIDI。它与 [CATALOG.md](../CATALOG.md) 中的推荐最终版分开：候选文件可以下载和讨论，但只有经过审核的版本才会成为普通玩家默认下载项。

## 目录规范

```text
community/
├─ README.md
├─ _template/
│  ├─ README.md
│  └─ submission.yml
└─ <曲目英文标识>/
   └─ candidate-<GitHub-ID>-v<版本号>/
      ├─ <曲目>_candidate.mid
      └─ submission.yml
```

## 展示表格

维护者在本文件追加投稿条目即可。推荐格式：

| 曲目 | 投稿者 | 状态 | 版本 | 下载 | 改动说明 |
| --- | --- | --- | --- | --- | --- |
| 示例曲目 | `@GitHub-ID` | 待审核 | v1 | 投稿合并后填写实际 MIDI 下载链接 | 这是填写格式示例，不含真实 MIDI。 |

状态只使用：`待审核`、`已验证候选`、`已替换为推荐最终版`、`已归档`。

真实投稿的下载链接格式如下；把占位文字替换为实际文件名即可：

```md
[下载 MIDI](<曲目英文标识/candidate-GitHub-ID-v1/曲目_candidate.mid?raw=1>)
```

本 README 的表格是社区候选的唯一展示目录。每个合并的投稿 PR 都应同时补充或更新相应的一行。

GitHub 不会播放 MIDI；“下载”链接是正常展示方式。若投稿者另有权公开试听音频或钢琴卷帘图，可额外添加预览链接。
