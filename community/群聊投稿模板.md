# 群聊投稿模板

适用于飞书、抖音群等不方便直接发起 GitHub Pull Request 的渠道。请复制下面的内容，连同 MIDI 文件或可长期访问的下载链接一起发送；不要只说“文件在群里”。

```text
【曲名】

【MIDI 文件】
文件名：
获取方式：直接附 MID / 网盘链接 / GitHub 链接
文件角色：原始输入 / 修谱候选 / 默认可演奏版

【演奏状态】
默认可演奏版 / 候选演奏版 / 仅供审计或修谱素材 / 不确定，请维护者判断

【导入音高】
0（默认）/ -12（降一个八度）/ +12（升一个八度）/ 其他：
说明：

【速度设置】
默认 / 具体数值，例如 1.11x：

【其他导入或演奏设置】
没有请写“无”。例如：使用哪一条旋律轨、是否去尾部静音、是否需要关闭某个音轨。

【已试听的平台】
平台、设备或版本：
试听结果：
已知问题：

【来源与授权说明】
原始来源：
权利归属或授权方式：
是否允许公开发布、修改和再分发：

【修谱说明】
相对原文件做了哪些修改：
是否保留原始输入文件：

【备注】
```

文件名只用于快速提示。默认设置通常不必写进文件名；非默认且会显著影响演奏结果的参数可以写为 `曲名（候选演奏版·导入音高-12）.mid`。完整、权威的信息仍以这份投稿说明和合并后的 `submission.yml`、`MIDI-MANIFEST.yml` 为准。

提交即表示你有权按本仓库的 CC BY 4.0 条款公开 MIDI 与说明。请勿提交账号资料、私人联系方式、授权书原件、本机绝对路径或未经授权的音乐资料。
