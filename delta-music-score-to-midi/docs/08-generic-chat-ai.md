# 普通聊天 AI 的通用提示词

本页适用于 ChatGPT 网页版/手机端、DeepSeek 网页/App、普通豆包聊天，以及任何没有明确本机 Skill 安装能力的聊天 AI。

先上传你的 MIDI、PDF、乐谱图片或简谱文件。不要只粘贴 `C:\完整路径`，因为云端聊天通常看不到你的电脑文件。

## 先发送这段能力确认

```text
我将上传一个 MIDI、PDF 或乐谱图片。

请先说明你能否：
1. 读取这个附件；
2. 联网检索来源页面；
3. 运行 Python；
4. 输出可下载的 .mid 文件。

若不能完成其中任何一项，请不要声称已经运行脚本或生成经过验证的 MIDI；
改为给我可复核的分析、reviewed_score.json 草稿、检索关键词或本机操作步骤。
```

然后发送下面最符合情况的一段。不要在普通聊天中写 `$delta-music-score-to-midi`；那是 Codex 的 Skill 名称。

## 已有 MIDI

```text
我已上传一个 MIDI。请先审计它、判断结构类型，并列出最可能的旋律候选及理由。
不要默认提取整首编曲的最高音；旋律可能由多个音轨交替演奏。

先给我处理方案、风险和待确认事项。
等我明确确认后，才提出或执行下一步。
```

## 已有 PDF、图片或简谱

```text
我已上传一份我有权用于私人使用的乐谱。
请按页、谱表和小节建立 reviewed_score.json 草稿，
列出所有不确定的音高、时值、休止、临时记号、反复、连音线和八度标记。

不要把 OCR 或推断当作已确认事实，也不要在未经我确认时声称已编译 MIDI。
```

## 还没有资料，需要寻找

```text
请为《[曲名]》寻找适合提取单旋律的乐谱或 MIDI。
优先公开、授权清楚、容易复核的来源。
MidiShow 可以作为权利情况未知的技术备用方案，不要直接排除。

对每个候选只提供：原始页面、格式、费用或访问条件、授权/权利状态、
技术适用性和不确定点。
不要下载、登录、付费，或绕过访问限制。
如果你没有联网能力，请只给我检索关键词和来源类型。
```

## 你最终应拿到什么

即使聊天 AI 能帮助分析，导入三角洲音乐播放器的最终文件仍应是 `*_melody_only.mid`。Python 播放器 `.py` 不是 MIDI 文件，也不能导入到播放器的 MIDI 导入界面。

若聊天 AI 没有可靠的本机执行能力，使用本仓库的 Codex 路线完成最终编译和验证，才可把结果称为“已验证的 MIDI”。
