# 《太阳照常升起》多轨 MIDI：主旋律结构判断

- **输入：** `input/太阳照常升起.mid`（用户提供，不使用此前的单小提琴 MIDI）。
- **SHA-256：** `579063299d6052c9e4d4adf3d862c02453ae42c2ea6cbbc90e9993ff7e63d37f`。
- **用途／权利：** 已确认私人技术流程；权利状态为 `unknown`，不构成公开或再分发衍生 MIDI 的许可。
- **审计证据：** [track_report.md](track_report.md) / [track_report.json](track_report.json)。

## 结论

没有一条可直接等同“全曲主旋律”的源轨。此文件把前景旋律在长号、弦乐、大提琴和长笛之间交接；将这些段落合并为一个 MIDI 是**单线改编**，不是从原文件中无损抽出的一条既有轨。

下面是证据最强的主旋律承载段。时间以 MIDI quarter-beat（`q`，480 tick）表示；文件在 120 BPM 下运行至尾端事件，因此 1 q = 0.5 秒。

| 段落 | 源轨／GM 乐器 | 范围 | 证据与处理 |
| --- | --- | --- | --- |
| A | 轨 1／57 Trombone（长号） | 1.00–68.99 q | 早段 59 个起音严格单声部，D4–D5；从 113.99 q 起该轨转为双音和声，故**不能**把整条轨直接抽出。 |
| B | 轨 4／49 String Ensemble 2（弦乐合奏 2） | 81.00–184.99 q | 81–113 q 是成对的八度齐奏，旋律在上方音；113 q 后为单音高声部。将 81–113 q 取上音可以形成连续旋律，但这是针对已识别旋律段的、可说明的简化。 |
| C | 轨 6／42 Cello（大提琴） | 185.00–272.00 q | 69 音符、严格单声部、零重叠，C3–G#4；是后段最明确的独立旋律声部。 |
| D | 轨 7／73 Flute（长笛） | 270.50–281.00 q | 14 音符、严格单声部、零重叠，C4–C5；它在 C 段最后一个 C4（269–272 q）尚未结束时，于 270.50 q 进入。 |

## 排除依据

- **轨 2（61 Brass Section）**：三音同起与 39 次重叠，像和声铜管，不可作为单线。
- **轨 3（48 String Ensemble 1）**：最多三音同时，135 次重叠，是和弦／节奏性弦乐织体。
- **轨 5（32 Acoustic Bass）与轨 8（58 Tuba）**：低音伴奏，内容和节奏相近，音域 G#1–D3。
- **轨 1 的后半（113.99–148.99 q）**：转为双音伴奏，不能把其中音符与旋律段混在一起后再机械取最高音。

## 完整单线版本的必要选择

建议的主线是 **A → B → C → D**，但 C 与 D 存在 **270.50–272.00 q 的 1.5 拍重叠**；这不是可由技术事实自动消除的情况。

请选择一项，再生成 `*_melody_only.mid`：

1. **保留大提琴收束（保守、忠实 C 段）**：C 保留到 272 q；D 从 272 q 的 C5 开始。这会舍弃长笛进入前的 G4–A#4 三个上行音。
2. **以长笛为结尾（更明亮的终止线）**：C 在 270.50 q 结束，并从 D 的 G4 开始。这会缩短大提琴最后一个 C4（原为 269–272 q）。

无论选择哪项，都会保留原始前奏空拍、120→127.66 BPM、4/4→3/4、D minor→G minor→C minor 的时间图；不会按整曲最高音选择，也不会默默折叠单个音到其他八度。
