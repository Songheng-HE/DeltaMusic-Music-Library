# 可下载演奏版

这是给普通玩家使用的统一下载目录。这里的文件名统一采用：

```text
中文曲名（版本说明·关键导入参数）.mid
```

它们是曲目工作目录内相应 MIDI 的逐字节副本，便于下载后识别，不取代原始输入、报告或历史版本。每份文件的来源路径、状态和 SHA-256 都记录在仓库根目录的 [MIDI-MANIFEST.yml](../MIDI-MANIFEST.yml) 与 [CHECKSUMS-SHA256.txt](../CHECKSUMS-SHA256.txt) 中。

只有会明显影响演奏结果的非默认参数才会写入文件名。例如文件名中的 `导入音高-12` 表示：在播放器导入界面把音高/八度偏移设为 `-12`，即降一个八度；这不会改写 MIDI 文件本身的音符。

目前 [月半小夜曲（压缩休止候选·导入音高-12）](<月半小夜曲（压缩休止候选·导入音高-12）.mid?raw=1>) 导入时必须使用该 `-12` 设置。完整参数以 [曲目目录](../CATALOG.md) 和 [MIDI-MANIFEST.yml](../MIDI-MANIFEST.yml) 为准。

请先查看 [曲目目录](../CATALOG.md) 的状态：候选版可以试听和使用，但不应被误认为已经定稿的最终版。
